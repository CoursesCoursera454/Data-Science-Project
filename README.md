# Data-Science-Project

Main goal of this project is to create analysis of Space X launch process and find to optimize new process.

There are multiple Jupyter notebook files contained in this repository.

### 01_Access Space X with API.ipynb
It contains example of downloading data with Space X API and transforming to pandas dataframe.

### 02_Webscraping_lab.ipynb
This notebook contains examples of web scraping of Space X Wikipedia page. It mainly uses requests module and basic transformation.

### 03_Data wrangling.ipynb
Notebook contains transformation of data with pandas library.

### 04_EAD-dataviz.ipynb
This notebook is basis for exploratory data analysis. It displays basic relations between variables in dataframe.

### 05_EDA-SQL.ipynb
In notebook it is performed basic data analysis with SQL from SQLite database. Main analysis is aggregation of data and filtering on specific criteria.

### 06_Launch-site-location.ipynb
Main analysis is performed on maps. It performs basic visualization on maps and distances.

### 07_Machine-Learning-Prediction.ipynb
This notebook contains specific machine learning analysis on classifying success of Space X landings. Four techniques were used to classify expected landings of level 1 booster.

### Dash application spacex_dash_app.py
This application creates dashboard for inspecting relations on launch sites and payloads.
